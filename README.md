# Android TV App Building Skills

A collection of agent skills for building Android TV / Google TV apps. Covers fundamentals, Compose for TV, playback, content discovery, memory optimization, games, and quality/publishing.

## Skills

- `android-tv-fundamentals` — project setup, manifest, hardware, navigation, controllers
- `android-tv-compose` — Jetpack Compose for TV
- `android-tv-playback` — media playback, MediaSession, ambient, Now Playing, audio, memory
- `android-tv-discovery` — home screen channels, Watch Next, search, previews
- `android-tv-memory` — memory optimization for TV
- `android-tv-games` — TV games
- `android-tv-quality` — accessibility, publishing, checklist, quality

## Installation

```bash
npx skills add aashish1332/android-tv-skills
```

Works with Claude Code, OpenCode, Codebuff/Freebuff, and other Agent Skills compatible clients.

## Compatibility

Skills are placed in all standard discovery locations (`.claude/skills/`, `.agents/skills/`, `.opencode/skills/`, `skills/`) so they load on Claude Desktop, OpenCode Desktop, and Freebuff Desktop.
